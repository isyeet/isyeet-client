# Third-party software

Official Signal libsignal-protocol v0.103.0 is pinned to `ba133bd3457f556fbf56db0a5ab985de0af79da6`, under AGPLv3.

Cargo.lock records exact Rust versions and immutable Git revisions. The matching dependency-source archive preserves each component and its license notices. Apple system frameworks are supplied by Xcode/iOS and are not redistributed here. Swift has no third-party package dependencies.

Upstream does not support third-party libsignal consumers. Pinning a version does not establish absence of vulnerabilities. This application still requires independent security review.
